## V24 原始 GDS 核验（本轮核心技术结果）

数据源（只读）：
`D:/Codex_RF11_Project/outputs/ASML_100D_OCTAGON_4IN1_7P2_CHROME_V24/ASML_100D_OCTAGON_4L_STACKED_EXTERNAL_BAR_ONLY_REVIEW_V24.gds`
cell `OCTAGON_4L_STACKED_EXTERNAL_BAR_ONLY_V24`，unit 1e-6 / precision 1e-9，200 个多边形，
图形单位为掩模面 μm，晶圆面 = 掩模面 / 5。工具：gdstk 1.0.1（cp314 wheel，
安装到 `work/pylib`，未改动系统 Python 环境；系统只有 Python 3.14，D 盘自带的 cp312 gdstk 不可用）。

逐层实数 L1=80、L2=28、L3=28、L4=28，与版本文档
`docs/source_records/2026-09-28_addendum/04_掩模板与版图版本索引.md` 的 JSON 几何摘要
"M2约80；Via 28；M3_PAD 28；Passivation 28"逐项吻合 → 层归属由原始数据确认：
**L1=M2 线圈、L2=Via、L3=M3 跨线与 PAD、L4=钝化/焊盘开口**（L90/91/92 为对准与外框条）。

以 Via 圆聚类得到 4 个子器件中心，掩模面 (-7176.7,-7467.4)、(-7176.7,7532.6)、
(7823.3,-7467.4)、(7823.3,7532.6) μm，晶圆面间距 3000 μm。
**四个子器件的相对坐标逐位相同 → V24 的"四合一"是同一设计的四份复制，不是四种设计。**

DEV1（以器件中心为原点的晶圆面坐标）建模数据：

| 层 | 图形数 | 关键尺寸（晶圆面） |
| --- | --- | --- |
| L1 M2 | 16 | 导体等效宽度 9.87–9.95 μm（另有一处 7.07 μm 的 21.95×13.99 μm 小图形，90 顶点） |
| L2 Via | 4 | 直径 5.9949 μm（记录写 6 μm），圆心 (417.27,186.91)、(115.26,-414.44)、(-201.51,355.22)、(-331.01,-127.68) |
| L3 M3+PAD | 4 | 每条形等效宽 134.30–147.22 μm，外包 0.96×1.10、0.74×1.03、1.09×0.86、1.05×0.82 mm |
| L4 钝化开口 | 4 | 450.000×450.000 μm，位于四角 (895.34,953.48)、(895.34,-966.52)、(-1024.66,953.48)、(-1024.66,-966.52) |

连接关系（原始多边形包含判定）：每个 Via 圆心的金属覆盖恰好是 **一个 L1 图形 + 一个 L3 图形**，
且四个 450 μm 钝化开口下方均为 L3 金属 → 拓扑为
**M2 绕组 → Via → M3 宽带 → 500 μm 焊盘（450 μm 开窗）**，四个端子对应两绕组各两端。
由 (500-450)/2 = 25 μm 反推 L3 焊盘 500 μm，与记录"500 μm PAD、450 μm 开口、金属包围 25 μm"一致。

复现 2026-10-13 记录：Via 直径、M2 包围 3.996 μm、M3 包围 8.980/6.333/8.980/7.409 μm 全部逐位重现。

1. "四处 Via 的 M2 最小金属包围约 3.996 μm"过泛 —— 每器件实为三个 3.996 μm、
   一个 **2.7712 μm**（对应 M2 上那个 21.95×13.99 μm 小图形，最紧处只 2.77 μm）。
2. Via 实际直径 5.9949 μm，不是整 6 μm；M3 各包围值在一器件内重复出现两次（因四份复制）。

### 新的实质阻塞：V24 的绕组串联关系无法由现有 GDS 确定

- M2 各同心导体带之间**没有任何接触**（最近间距处处 ≈8.9 μm），而 4 个 Via 各自只覆盖
  1 条 M2 带与 1 条 M3 带。所以"M2 若干匝如何串成两个绕组、哪两个端子属于同一绕组"
  无法从这份叠层 review GDS 单独判定。
- 制版用的 `..._TONE_D_CLEAR_FEATURES_L1_V24.gds`（164 个多边形，单层 L1）不是"M2 专用层"：
  review L1 的 20 个不同面积值在该文件中全部出现，且文件里最大面积 6,757,827 μm²（掩模面）
  = 270,313 μm²（晶圆面），与 review 中 **L3** 环形图形面积相同 → 该文件是把四层的透光图形
  按四窗排版合并到一条 GDS 层上，符合版本文档"四个窗口分别放 M2 线圈、Via、M3+PAD、
  Passivation/Pad-opening 图形"。因此它也不能直接给出 net 连接。
- 影响：HFSS 建 net、端口归属（哪两个 Via 属于初次级）与解析电感都依赖这一信息。
  下一步应查制版审核产物 `validation_V24.json`、叠层 DXF/预览与版图源文件，
  或向作图者确认 netlist；不能靠猜。
